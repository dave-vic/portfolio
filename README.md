# Davida Dzato · Portfolio

Next.js site built from the Figma file "Portfolio · Homepage concept".

- `app/` pages · `components/` sections · `public/` images, fonts and CV
- Layout units: `--u` = one Figma pixel at the current frame (430 mobile, 834 tablet, 1728 desktop)

```bash
npm install --legacy-peer-deps
npm run dev
```
